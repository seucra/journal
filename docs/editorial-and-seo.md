# Editorial and SEO workflow

`blog.seucra.tech` is the canonical home for original writing. Publish here first. Syndicate only evergreen, technical articles elsewhere after publication and point readers back to this original URL.

## Before publishing

1. Write from work you can explain and attribute accurately.
2. Use a specific title, a one-sentence `description`, one primary category, and 3–6 useful tags.
3. Add an explicit `date` with the `+0530` offset; use `last_modified_at` for substantive updates.
4. Add a local feature/social image when the post needs one; do not use unattributed images.
5. Link to the relevant portfolio page, GitHub repository, package, or upstream documentation where useful.
6. Link back to the portfolio only when it helps the reader; never add links merely to repeat keywords.

## Claim standard

State what was built, configured, learned, measured, or decided. Do not claim production readiness, security guarantees, research results, scale, or authorship of forked/upstream work without evidence.

## After publishing

1. Check the rendered title, description, canonical URL, social preview, and internal links.
2. Add the post to the related portfolio project only if the relationship is real.
3. Share a concise summary later on LinkedIn/X. For an evergreen technical article, optionally syndicate to Dev.to with this site as the original source.
4. Submit the new sitemap URL in Search Console only after the page is public and correct.
